# Plantas ES — испаноязычный сайт о растениях

Отдельный проект: уход за комнатными и садовыми растениями, вредители, грунты и удобрения, огород. Рекламные кабинеты (/opt/google-ads-mcp, /opt/apple-ads-mcp) и другие сайты (/opt/astro-es, /opt/klimin-site, /opt/pets-es, /opt/limpieza-es) не трогать.

## Правила работы
- Все сообщения пользователю — на русском, включая промежуточные. Контент сайта — на нейтральном испанском, понятном и в Испании, и в ЛатАм; региональные названия растений давать синонимами (potus/poto, sábila/aloe vera, bugambilia/buganvilla, palo de agua/palo de Brasil).
- Ничего не публиковать в интернет (деплой, DNS, покупка домена) без явного «да». Сначала показывать превью на *.pages.dev.
- Секреты не выводить и не повторять; хранить в /opt/plantas-es/.env (chmod 600).
- Решения и изменения кратко логировать в /opt/plantas-es/CHANGELOG.md.
- На сервере 3,7 ГБ RAM + 4 ГБ swap: сборки запускать последовательно, тяжёлые задачи не распараллеливать. Неиспользуемые окна VS Code закрывать.

## Цель и деньги
Органический трафик Google на испанском → реклама (AdSense / Ezoic и т.п.) и партнёрские ссылки на товары для ухода. Позже, если пойдёт: свой магазин на Shopify с ходовыми товарами и приложение.
- Живые растения онлайн не продавать: почти весь спрос на покупку — `vivero` / `vivero cerca de mi` (ищут питомник рядом). Без них «comprar plantas…» ≈ 10,6 тыс./мес в Испании, 3,2 тыс. в Мексике.
- Товары для ухода — основной товарный спрос: горшки, семена, грунт, удобрения, теплицы ≈ 154 тыс./мес в Мексике и 98 тыс. в Испании; клик ≈ $0,06–0,57. Партнёрские блоки в карточках растений («этой орхидее нужен такой субстрат и горшок»). Партнёрские ссылки помечать.
- Приложение (позже): определитель растения по фото + напоминания о поливе + связь с карточками сайта. Перед разработкой проверить App Store/Google Play так же, как в /opt/pets-es (research/pets_apps.mjs), и спрос через блок «напоминания в приложении» с листом ожидания.

## Стек (как в /opt/pets-es и /opt/astro-es)
- Astro (статическая генерация, JS только на страницах инструментов) + Cloudflare Pages/Workers, код в приватном репозитории GitHub, отдельный deploy key. Спросить, можно ли использовать тот же токен Cloudflare.

## Доступы (уже настроены, искать не нужно)

Запуск: `cd /opt/google-ads-mcp && set -a && . ./.env && set +a && node /opt/<проект>/research/<скрипт>.mjs`. Эндпоинты: `POST /customers/6962355647:generateKeywordIdeas` (`keywordSeed`, `pageSize` до 5000) и `:generateKeywordHistoricalMetrics` (точные объёмы по списку). Пример: research/*_kw.mjs в этом проекте.
  - Языки: es 1003, en 1000, pt 1014. Страны: ES 2724, MX 2484, US 2840, AR 2032, CO 2170, CL 2152, PE 2604, VE 2862, EC 2218.
  - Валюта аккаунта CLP: ставки делить на ≈950, чтобы получить USD. Апострофы в запросах дают ошибку.
  - В рекламных кабинетах ничего не менять — только чтение планера.
- **Search Console (только чтение):** `cd /opt/shopify-mcp && node scripts/gsc.mjs sites | sitemaps <site> | query <site> <start> <end> [page,query] [limit] | inspect <site> <url>…` (Node из /opt/astro-es/.tools/node/bin). Сайт указывать как `sc-domain:домен` или `https://домен/`. Отчёта «Индексирование страниц» в API нет: проверять URL через inspect (≈2000 в день на ресурс, по одному с повтором при 500). Новый домен сначала подтвердить в Search Console и добавить на тот же аккаунт.
- **GA4:** через коннектор GA4 (run_report) после создания ресурса для сайта.

## Спрос (Keyword Planner, 2026-11-19)
Скрипт research/plants_kw.mjs (запуск из /opt/google-ads-mcp с его .env), данные plants_matrix_es.json и plants_clusters_es.json. Страны: ES, MX, US (испанский), AR, CO, CL, PE. Цифры — запросы в месяц, оценка Google, для сравнения тем, а не прогноз трафика.
- **Карточки растений:** 103 растения × 20 намерений. У 90 растений ≥1000 запросов/мес по уходу и смежным намерениям. Лидеры по уходу: орхидея, драцена (palo de agua/Brasil), сансевиерия, антуриум, каланхоэ, бонсай, гортензия, лаванда, тюльпан, бегония, пуансеттия (nochebuena — сезон к Рождеству), спатифиллум.
- По намерениям: cuidados ≈203 тыс., tipos ≈162 тыс., significado ≈77 тыс., reproducir ≈37 тыс., hojas amarillas ≈31 тыс., poda ≈24 тыс., plantar ≈17 тыс., sol/sombra ≈16 тыс., riego ≈9 тыс. Голое название растения (≈17,9 млн) не считать: там смешаны еда, имена, фото, магазины.
- **Кластеры:** списки (plantas colgantes 14,8 тыс., de sol 12,1 тыс., poca luz 8,1 тыс., para baño 5,4 тыс., tóxicas para gatos 4,4 тыс.) ≈163 тыс.; грунты (perlita 18,1 тыс., tierra para plantas 9,9 тыс., sustrato para orquídeas 6,6 тыс.) ≈140 тыс.; вредители (pulgones 18,1 тыс., cochinilla, araña roja, oídio) ≈75 тыс.; удобрения (humus de lombriz 27,1 тыс.) ≈68 тыс.; огород ≈83 тыс.
- **Выдача (грубая проверка):** по уходу за растениями в топе в основном новостные сайты (El Tiempo, Cronista, TV Azteca, Excelsior), специализированных сильных сайтов почти нет. Риск: Google отвечает на простые вопросы сам (AI Overviews), поэтому страницы должны давать больше, чем короткий ответ: таблица ухода, фото проблем, календарь, инструмент.

## Контент и безопасность (обязательно)
- Токсичность для кошек и собак — только по ASPCA (Toxic and Non-Toxic Plants) и указывать источник и дату проверки. Это связка с /opt/pets-es (ссылки между сайтами возможны позже, по решению пользователя).
- Не писать лечебные свойства и дозировки трав («beneficios del romero» для здоровья) — это медицинская тема; намерение `beneficios` исключено из плана.
- Вредители: только методы низкого риска и средства по инструкции на этикетке; без самодельных токсичных смесей и доз пестицидов.
- Огород и посадка: календарь по полушарию (Аргентина и Чили — сезоны наоборот), это отличие от конкурентов.
- Политика Google scaled content abuse: не выпускать сотни однотипных карточек сразу; каждая карточка — с проверенными данными о растении (свет, полив, температура, токсичность, размножение, частые проблемы). Публиковать партиями и смотреть индексацию в Search Console.

## План страниц
research/content_plan.csv (колонки wave, topic, format, url, query, best, volume, variants, gate); пересборка `python3 -I research/build_plan.py`, сводка в research/plan_summary.txt. Итого **275 страниц + 719 строк** FAQ/таблиц. Это черновик: группировка запросов автоматическая, перед публикацией каждой партии проверить дубли намерений вручную.

| Волна | Тема | Страниц | Строк | Условие публикации |
|---|---|---|---|---|
| 1 | Карточки топ-40 растений | 40 | 0 | Данные по уходу и токсичности проверены |
| 1 | Списки, грунты, удобрения, вредители, проблемы | 81 | 199 | Без дублей намерений |
| 1 | Инструменты | 4 | 0 | Логика покрыта тестами |
| 2 | Остальные 63 карточки + подстраницы (виды, размножение, желтые листья, обрезка) | 127 | 451 | Как волна 1 |
| 3 | Огород | 23 | 69 | Календарь по полушарию |

- format=`page` — отдельная страница; `faq-or-table` — строка в FAQ или таблице родительской страницы, без отдельного URL.
- `significado` (≈77 тыс.) — только строки FAQ, без обещаний «удачи и энергии» как факта.
